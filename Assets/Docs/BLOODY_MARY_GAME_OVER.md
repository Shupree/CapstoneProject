# 블러디 메리 게임 오버 구현

구현 기록: 2026-10-12 (한국 시간)

## 현재 동작

- 1페이즈는 인터넷 창이 열린 동안 마지막 유효 메리 클릭/창 닫기 이후 10초간 아무 행동이 없으면 실패한다. 일반 메리 클릭은 기존 단계 초기화를 유지하면서 제한 시간도 초기화한다. 공격 메리 클릭·단계 이동도 제한 시간을 초기화한다. X 또는 인터넷 아이콘으로 닫으면 10초를 초기화하고, 닫힌 동안은 정지한다. 스크롤·창 드래그·메모장 조작은 초기화 행동에 포함하지 않는다.
- 1페이즈 실패 시 전체 데스크톱에 검은색 50% 덮개를 표시하고, 그 위 화면 중앙에 공격 메리 이미지를 표시한다. 2초 후 UI를 포함한 전체 화면이 검게 덮인다.
- 2페이즈는 시작부터 30초 내 정답을 전송해야 한다. 문장 생성/수명은 기존처럼 창을 닫으면 정지하지만, 전체 30초 제한은 계속 흐른다. 닫힌 동안 제한을 넘으면 창을 열어 실패를 표시한다. 실패 시 어절 입력/생성을 멈추고 창 내부를 붉은 `네가 죽였어` 반복 문장으로 채운다. 2초 후 전체 화면이 검게 덮인다. 30초 전에 정답을 전송한 경우 시간 제한과 실패 연출이 중단된다.
- 공통 암전 후 손 12개가 0.07초 간격으로 누적 표시된다. 전체 투명 PNG를 사용하며 크기·위치·회전·투명도·표시 순서는 씬에 고정했다. 마지막 손 표시 후 0.4초 뒤 전체 화면이 붉게 전환되고 흰색 `Signal Lost`, `Retry`, `Exit`을 표시한다.
- 실패 시작부터 기존 게임 UI 입력을 차단한다. Retry/Exit은 최종 화면에서만 활성화한다. Exit은 현재 아무 동작도 하지 않는다.
- Retry는 씬을 다시 로드하지 않는다. 조사 결과와 메모를 유지하고, 테마 전환 당시 창 위치를 복원하여 창을 닫는다. 배틀 이미지 테마와 기존 볼륨을 유지하고 배틀 BGM을 처음부터 재생한다. 1페이즈 첫 단계·무행동 시간·2페이즈 문장/선택 어절/제한 시간을 초기화한다. 통화·프로그램 실행·화이트 노이즈·스위치 연출을 다시 재생하지 않는다. 인터넷 아이콘으로 1페이즈를 다시 연다.
- 첫 손 이미지가 표시되는 프레임에 `GameOver_Hands.wav`(1.17초)를 한 번 재생한다. 손 표시 시점을 하나의 경과 시간 기준으로 계산하여 이미지마다 대기 프레임 오차가 누적되지 않도록 했다. 붉은 화면으로 전환하면 손 효과음을 멈추고 `No_signal.mp3`(7.08초)를 한 번 재생한다. 실제 오디오 샘플 재생 위치 기준 마지막 1초(현재 약 6.08초부터)에 초기 볼륨에서 0까지 선형 페이드 아웃한다. 빨간 화면은 음원 종료 후에도 유지된다.
- Retry/컨트롤러 비활성화 시 게임 오버 음원과 페이드 코루틴을 중단하고 페이드 전 볼륨을 복원한다. 다음 게임 오버에서도 같은 설정 볼륨으로 시작한다. 기존 배틀 BGM·효과음 볼륨은 변경하지 않았다.

## 씬 편집 안내

- 씬: `Assets/Scenes/Battle_Proto.unity`.
- `ExploreProtoMessenger`의 `BloodyMaryPhaseController.Inactivity Limit`: 1페이즈 제한, 기본 10초.
- 같은 오브젝트의 `BloodyMaryPhaseTwoController.Time Limit`: 2페이즈 전체 제한, 기본 30초.
- 같은 오브젝트의 `BloodyMaryGameOverController`: 실패 표시 시간(2초), 손 표시 간격(0.07초), 손 완성 후 대기(0.4초)와 UI 참조.
- `ExploreProtoMessenger/GameOverAudioSources/HandsAudio`, `SignalLostAudio`의 AudioSource `Volume`에서 각 게임 오버 효과음 볼륨을 편집한다. 씬에 저장한 별도 2D AudioSource이며 Play On Awake와 Loop는 꺼져 있다. `BloodyMaryGameOverController.Signal Fade Seconds`는 끝부분 페이드 시간이며 현재 1초다. `AgentScripts/ConnectBloodyMaryGameOverAudio.cs`는 두 신규 소스와 참조만 추가한 일회성 편집 기록이다.
- `BattleGameOverCanvas`: 전체 화면 연출용 별도 Overlay Canvas. 정렬 순서 32000으로 기존 UI 위에 표시한다. 평소에는 비활성이다.
- `DimScreen`: Image 색 검정/알파 0.5. `CenteredAttackMary`: 중앙 이미지·크기. `BlackoutAndHands/Hand_01~12`: 각 손의 RectTransform과 RawImage 색/투명도. `GameOver_hand.png`는 여러 조각으로 슬라이스되어 있으므로 전체 텍스처를 RawImage로 표시한다.
- `SignalLostScreen`: 배경색 RGB(184, 0, 0). `SignalLostTitle`, `RetryButton/Label`, `ExitButton/Label`에서 문구·색·폰트·배치를 편집한다. 기존 프로젝트 폰트를 사용한다.
- `ExploreProtoCanvas/ClearedInternetWindow/PhaseTwoDeathWarning`: 창 내부 마스크와 반복 문장 12행. 화면을 가득 채우기 위해 가장자리 문장은 마스크로 잘라낸다.
- 모든 UI는 씬에 미리 저장했다. Play 진입/화면 전환에서 UI를 새로 생성하지 않는다. `AgentScripts/AuthorBloodyMaryGameOver.cs`는 신규 연출만 구성한 일회성 편집 기록이며 재실행을 차단한다.

## 정적 확인과 사용자 테스트

2026-10-12 타격음 교체 후 볼륨 두 배 요청: `BloodyMaryGameOverController`의 `Hands Volume Multiplier`를 2로 저장했다. 손 효과음은 AudioSource Volume × 해당 배율로 한 번 재생한다. 기본 배율은 1이며 Inspector의 0~5 슬라이더에서 조절한다. 재생 시에도 0~5로 제한한다. `HandsAudio`에 사용자가 교체한 `monitor_hands_dark 1.wav` 참조를 유지했다. 컴파일/참조/배율/저장을 정적으로 확인했으며 실제 청취는 하지 않았다. 두 페이즈 실패 시 소리 크기/왜곡, 붉은 화면 전환과 Retry 중 이전 효과음 중단을 사용자 확인한다.

2026-10-12 정적 확인: 연결 프로젝트 `D:/CWS/Zol_Project`, `Battle_Proto` 편집 모드에서 작성했다. Unity 스크립트 컴파일 오류 없음. 저장 씬의 10초/30초 연결, 50% 검은 덮개, 공격 메리 참조, 손 12개와 전체 텍스처, 반복 문장 12행, 높은 Canvas 순서, 초기 숨김, Retry/Exit 이벤트 각각 1회 연결을 확인했다. 기존 통화 직렬화 내용·AudioSource 볼륨을 보존했다. 사용자가 이미 수정한 효과음·새 손 자산·기존 씬 편집을 보존했다.
