# 대사별 화상 통화 스프라이트 편집

구현: 2026-10-12 (한국 시간)

## 직접 조절하는 방법

1. Play를 멈추고 원하는 씬을 연다.
2. Hierarchy에서 `ExploreProtoMessenger`를 선택한다.
3. 탐색 통화는 `Explore Proto Messenger → Call Lines`, 배틀의 세 사람 통화는 `Battle Proto Conversation → Call Lines`를 펼친다.
4. 해당 대사의 `주인공 스프라이트`, `시율 스프라이트`, `친구 스프라이트`에 Project의 원하는 Sprite를 끌어 넣는다. 예: `SpriteNew/Heroine_3`, `Client_2`, `Friend_4`의 스프라이트 하위 자산.
5. 씬을 저장한다. 탐색과 배틀의 대사 목록은 별도이므로 각 씬에서 저장한다.

- 지정한 인물만 해당 대사가 표시될 때 변경된다. 화자가 누구인지와 관계없이 한 대사에서 여러 인물을 동시에 바꿀 수 있으며 나레이션에서도 적용된다.
- `None`은 이전 이미지 유지다. 첫 대사가 비어 있으면 씬에 저장된 기본 이미지를 유지한다.
- 현재 새 항목은 모두 비워 두었다. 임의 표정/대사를 추가하지 않았다.
- 탐색 통화에는 주인공·시율 영상만 있으므로 친구 항목은 표시할 대상이 없다. 배틀 통화에서는 세 사람 모두 변경된다.
- 새 통화를 시작하면 씬 기본 이미지로 초기화한 뒤 첫 대사의 설정을 적용한다. 탐색 통화를 중간에 닫고 다시 시작하면 기존처럼 첫 대사부터 시작한다. 배틀 통화를 중간에 닫고 다시 열면 진행 대사와 표정을 유지한다.
- 기본 이미지는 `PlayerSprite`, `SiyulSprite`, 배틀의 `FriendPlaceholder`에 저장되어 있다. 새 실행마다 `VideoCallPortraits`가 이 기본 이미지를 기억한다.
- 스프라이트를 바꿔도 기존 Image의 RectTransform, 색, 원본 비율 유지, 마스크, 버튼과 대사 배치는 변경하지 않는다. UI를 새로 생성하지 않는다.
- 녹취록은 기존 대사 텍스트만 표시한다. 이미지 변경이 녹취 내용이나 단서/진행 조건을 바꾸지 않는다.

## 구현과 정적 확인

- `VideoCallPortraits.cs`: 씬에 존재하는 세 Image 참조, 기본 이미지 복원, 지정된 Sprite만 적용.
- `ExploreProtoMessenger.CallLine`과 `BattleProtoConversation.CallLine`: 기존 화자/대사/프로그램 음원 플래그를 보존하고 세 Sprite 필드를 추가했다. 대사 표시 함수에서 이미지 변경을 적용한다.
- 두 씬의 항상 활성인 `ExploreProtoMessenger`에 `VideoCallPortraits`를 저장했다. 탐색 컴포넌트와 배틀 컴포넌트는 각 씬의 같은 이미지 참조를 사용한다.
- `AgentScripts/ConnectVideoCallPortraits.cs`는 해당 연결만 추가한 일회성 편집 기록이다. 재실행을 차단하며 진행/미리보기 함수를 호출하지 않는다.
- 2026-10-12 정적 확인: Unity 컴파일 오류 없음, 탐색 9개/배틀 14개 대사와 기존 대사 직렬화 내용 보존, Image 참조/새 필드/씬 저장 확인. Play·입력·대사 진행 함수·미리보기·검증 스크립트는 실행하지 않았다.

## 배틀 테마 전환 전 두 사람 통화

- 배틀 통화 후 기존 프로그램/화이트 노이즈 연출을 거쳐 light-switch 효과음을 시작하는 순간, 다른 창을 모두 닫아 화상통화 창만 남기고 주인공 `Heroine_6`와 메리 `Merry`만 표시한다. 데스크톱 배경도 동시에 배틀 테마로 바꾼다. 메리의 표시 이름은 `M#!?A$Ry`다. 시율·친구 영상과 기존 대사/다음/닫기/드래그 영역은 이 단계 동안 숨긴다.
- 두 인물의 패널과 이미지 영역은 기존 3인 통화 크기와 동일하고 가운데에 나란히 배치한다. 현재 저장값은 패널 830.8×690, 이미지 영역 664.64×565.8이다. 창은 기존 2680×1500을 유지한다. 아래 대사 상자는 기존 UI를 복사해 화자와 본문만 비워 두었다. 다음 버튼이나 새 대사는 추가하지 않았다.
- 기본 1.5초를 유지한 뒤 남은 화상통화 창도 닫고 배틀 BGM 시작·아이콘 변경 및 1페이즈 시작을 실행한다. 유지 시간은 light-switch 음원 길이와 별개이며 실제 시간 기준이다. 기존 BGM은 유지 시간 동안 이어진다. 배경 참조는 `Background Change`, 대기 후 바뀌는 아이콘 참조는 `Sprite Changes`로 분리했다. Retry용 창 위치는 light-switch 시 다른 창을 닫기 전에 한 번 저장한다.
- `Battle_Proto` 씬의 `ExploreProtoMessenger → Battle Proto Retry Sequence → 중간 통화 유지 시간 (초)`에서 조절하고 씬을 저장한다. 0이면 대기 없이 테마를 전환한다.
- 중간 화면의 배치/이미지/이름은 `ExploreProtoCanvas/VideoCallWindow/IntermediateCall` 아래 `HeroineVideoPane`, `MerryVideoPane`, `IntermediateHeader`에 저장했다. 빈 대사 UI는 `IntermediateDialogueBox`다. 편집 후 초기 비활성 상태를 유지한다. 게임 실행 중 UI를 새로 만들지 않는다.
- 일반 통화의 대사별 이미지 설정은 그대로 유지한다. 중간 화면은 별도 Image를 사용하며 해당 대사 설정과 무관하다.
- 게임 오버의 Retry는 중간 통화나 light-switch를 다시 재생하지 않고 기존 배틀 테마 직후 체크포인트로 복귀한다.
- `AgentScripts/AddIntermediateBattleCall.cs`는 새 단계만 추가한 일회성 씬 편집 기록이다. 기존 대사·오디오 설정을 보존하고 게임/미리보기 함수를 호출하지 않는다.
- `AgentScripts/RefineIntermediateBattleCall.cs`는 패널/이미지 크기·이름·빈 대사 UI와 배경 참조 분리만 적용한 후속 편집 기록이다. 기존 창 RectTransform과 대사 설정은 보존했다.
- 2026-10-12 코드 컴파일과 저장된 참조·Sprite·기본 1.5초·초기 숨김·두 패널 크기를 정적으로 확인했다. 게임 테스트와 실제 연출 시간 측정은 수행하지 않았다.
