# 화상통화 카드 1페이즈 사용 안내

갱신: 2026-10-20. 대상: `Assets/Scenes/Battle_Proto.unity`.

## 진행 규칙

기존 배틀 3인 통화와 재시도 음원 이후 배틀 테마를 적용하고 `BattleCallWindow`를 연다. 기존 2인 중간 통화는 이 씬에서 건너뛴다. 새 창에서 주인공·메리가 1초 대치한 뒤 중앙에 “갑자기 화면이 이상해졌어.”를 2초 표시한다. 대치 카드와 대사를 숨긴 뒤, 불규칙하게 겹친 고정 위치에 카드가 0.1초 간격으로 하나씩 바로 나타난다. 이동 애니메이션은 없다. 2·3파트도 무작위 위치를 먼저 정하고 12개는 한 장씩, 18개는 두 장씩 순차 표시한다. 각 파트의 모든 카드가 표시된 뒤 입력과 10초 제한 시간을 시작한다.

| 파트 | 전체 카드 | 칼 든 카드 | 배치 |
| --- | --- | --- | --- |
| 1 | 9 | 1 | 씬의 고정 위치·순서. 기본 칼 카드는 Card05 |
| 2 | 12 | 3 | 각 카드의 위치와 겹침 순서 무작위 |
| 3 | 18 | 5 | 각 카드의 위치와 겹침 순서 무작위 |

칼 카드도 독립적으로 무작위 위치에 배치되므로, 파트 2·3의 칼 위치는 고정되지 않는다. 일반 카드 종료 버튼은 무반응이다. 칼 카드의 종료 버튼을 눌렀을 때만 해당 카드가 숨겨진다. 카드 본체를 누르면 맨 앞으로 오며 드래그할 수 있다. 종료 버튼에서 시작한 드래그는 카드를 이동시키지 않는다. 카드 전체가 통화창 내부에 있도록 이동을 제한한다.

각 파트 시작부터 **실제 시간 10초** 제한이다. 클릭, 드래그, 칼 카드 일부 제거로 시간을 초기화하지 않는다. 해당 파트의 칼 카드를 모두 제거하고 다음 파트로 넘어갈 때만 새 10초를 시작한다. 대치·대사·각 파트 순차 등장 중에는 타이머가 흐르지 않는다. 등장 중에는 종료 버튼과 드래그를 사용할 수 없다. 시간 초과 시 기존 게임 오버·효과음·Retry를 사용한다. Retry는 새 대치 연출부터 파트 1로 복귀한다.

파트 3 완료 시 남은 일반 카드도 숨기고 빈 화상통화 창에서 진행을 멈춘다. 타이머는 중단되고 완료 이벤트를 한 번 호출한다. 기존 인터넷 퍼즐과 2페이즈를 자동으로 열지 않는다. 게임 전체의 Time.timeScale을 변경하지는 않는다.

## 프리팹과 이미지 교체

`Assets/Prefab/BloodyMaryCall`:

- `CallCard.prefab`: 공통 프레임, Artwork, DismissButton/Icon, 카드 컴포넌트.
- `HeroineCallCard.prefab`: 주인공 대치 카드 Variant.
- `MerryConfrontationCard.prefab`: 버튼 없는 메리 대치 카드 Variant.
- `MerryCallCard.prefab`: 종료 버튼이 있는 일반 메리 Variant.
- `MerryKnifeCallCard.prefab`: 종료 버튼이 있는 칼 메리 Variant.

프레임은 공통 프리팹 루트 Image, 인물은 각 Variant의 Artwork Image, 종료 버튼 이미지는 공통 프리팹의 DismissButton/Icon Image에서 교체한다. 크기를 유지하고 이미지 비율을 보존하므로 이미지 교체만으로 판정이나 배치가 바뀌지 않는다. 버튼 클릭 영역은 아이콘보다 조금 넓다. 칼 판정은 파일명이 아닌 `BloodyMaryCallCard.isKnife`로 결정한다. 씬 인스턴스에 별도로 이미지를 덮어쓰지 않아 Variant 이미지 교체가 반영된다.

새 외곽 디자인을 만들지 않고 기존 `Assets/Sprite/ProtoType/SpriteNew/Window_Dark.png`를 사용했다. 좌측 아이콘과 하단 공간은 남겨 두었다. 교체는 `BattleCallWindow`의 Image에서 가능하다.

## 씬 편집 및 확장

- `ExploreProtoCanvas/BattleCallWindow/CallArea` 아래에 Confrontation, Dialogue, Part1~Part3가 저장되어 있다. 실행 중 새 UI를 생성하지 않는다.
- `Part1`의 카드 RectTransform을 편집하면 첫 파트의 고정 배치가 바뀐다. 드래그 후 Retry를 눌러도 처음 배치로 돌아온다.
- Part2·3의 저장 위치는 편집용 배치이며 실행 시 무작위로 바뀐다. 카드 크기와 스프라이트는 저장 설정을 따른다. 카드보다 통화 영역을 작게 만들거나 카드에 회전/음수 스케일을 적용하지 않는다.
- 중앙 문구는 `Dialogue/Text`에서, 시간은 `ExploreProtoMessenger`의 `BloodyMaryPhaseController`에서 변경한다. `Inactivity Limit`은 이전 필드명이며 현재 의미는 파트별 제한 시간이다.
- 추후 2페이즈 시작 함수를 `On Phase Completed`에 연결한다. 현재 기존 `BloodyMaryPhaseTwoController.BeginPhase` 연결은 제거돼 있다. 기존 2페이즈 오브젝트와 스크립트는 보존했다.
- `AgentScripts/AuthorCallCardPhase.cs`는 최초 프리팹·씬 작성용이다. 기존 자산이 있으면 중단하며 일상 편집용으로 재실행하지 않는다.

- 신규 `BloodyMaryCallCard.cs`: 카드 드래그, 맨 앞으로 이동, 창 내부 경계 제한, 종료 버튼 이벤트 전달을 담당한다.

## 확인한 사항과 사용자 테스트

2026-10-20: Unity 컴파일 오류 0건(기존 Editor 작성 도구의 obsolete API 경고 6건은 유지). 저장된 카드 수 9/12/18 및 칼 수 1/3/5, 프리팹 Variant 연결, 카드·스프라이트·버튼 참조, 완료 이벤트의 기존 2페이즈 연결 제거, Canvas GraphicRaycaster와 EventSystem 1개, 씬 저장을 정적으로 확인했다. Play 진입, 미리보기 순회, 게임 입력, 자동 테스트는 수행하지 않았다.

사용자 테스트 순서:

1. 탐색 씬에서 기존 메일 의뢰·첫 통화·검색·단서 수집·시율에게 결과 전달을 거쳐 배틀에 진입한다. 기존 조사 잠금과 3인 통화가 유지되는지 확인한다. Battle_Proto 단독 실행에서는 기존처럼 조사 완료 상태로 진입한다.
2. 3인 통화 마지막의 재시도를 진행한다. 기존 음원 이후 새 통화 창이 자동으로 열리고 대치 1초 → 중앙 대사 2초 → 카드 9개 순서인지 확인한다. 주인공·대사는 퍼즐 시작 시 사라져야 한다.
3. 첫 파트의 일반 카드 버튼을 눌러도 변화가 없는지 확인한다. 카드 본체로 드래그하고 겹친 카드가 맨 앞으로 오는지, 모든 모서리에서 카드 전체가 창 내부에 머무는지 확인한다. 종료 버튼에서 드래그했을 때 카드는 움직이지 않아야 한다.
4. 칼 카드 종료 버튼을 누른다. 첫 파트 완료 후 카드 12개/칼 3개, 이후 카드 18개/칼 5개로 바뀌는지 확인한다. 칼 카드를 일부 제거한 뒤에도 제한 시간은 연장되지 않아야 한다.
5. 파트별로 클릭·드래그하며 10초를 넘겨 본다. 정답을 모두 제거하지 않았다면 기존 게임 오버와 효과음이 나와야 한다. Retry 후 대치 연출·파트 1이 다시 시작되고 첫 배치가 같아야 한다. 파트 2·3은 재진입 시 무작위 배치여야 한다.
6. 마지막 칼 5개를 시간 내 제거한다. 남은 일반 카드도 사라지고 진행이 정지해야 한다. 10초 이상 기다려도 게임 오버나 기존 2페이즈가 시작되지 않아야 한다. 인터넷 아이콘으로 옛 퍼즐을 열 수 없어야 한다.
7. 실제 게임 해상도에서 한국어, 인물 비율, 종료 버튼 크기, 카드 겹침과 드래그, 좌측·하단 공간 침범 여부를 확인한다. Play 종료·씬 재열기 후 편집값이 보존되는지, Variant의 이미지를 교체했을 때 씬 카드에 반영되는지 확인한다.

## 2026-10-20 순차 등장 최종 수정

- BloodyMaryPhaseController의 StartStage에서 카드를 숨긴 상태로 최종 위치를 준비하고, 공통 RevealStage에서 이동 없이 하나씩 표시한다. 1파트는 고정 위치·등장 순서, 2·3파트는 무작위 위치·등장 순서다.
- 마지막 카드가 표시된 다음 프레임에 종료 버튼과 드래그를 활성화하고 10초 타이머를 시작한다. 등장 중에는 제거·드래그·시간 초과가 발생하지 않는다. Retry에도 동일하게 적용한다.
- Card Spawn Gap Seconds(기본 0.1초)로 모든 파트의 등장 간격을 조절한다. 이전 Spawn Origin과 Card Spawn Move Seconds 필드는 제거했다. 최초 작성용 AgentScripts/AuthorCallCardPhase.cs도 동기화했다.
- Unity 재컴파일 오류 없음. 게임 테스트는 수행하지 않았다.
- 사용자 확인: 각 파트의 카드가 이동 없이 자기 위치에 9/12/18개까지 순차 등장하는지 확인한다. 등장 중 칼 카드 종료 버튼·드래그는 반응하지 않아야 한다. 마지막 카드 등장 후부터 10초가 지나야 게임 오버가 발생해야 한다. Retry 후 첫 배치는 같고 이후 배치는 무작위인지, 마지막 파트 완료 후 진행이 정지하는지 확인한다. 한글 표시·잘림·겹침·입력 및 Play 종료 후 편집값 보존도 확인한다.

## 카드 크기 및 3파트 묶음 등장

- 퍼즐 카드(일반/칼 Variant)를 348×480에서 400.2×552로 15% 확대했다. 종료 버튼 영역은 82.8×82.8, 아이콘은 69×69다. 대치용 카드 크기는 유지했다. 씬 카드의 이전 크기 오버라이드는 해제해 Variant 크기를 상속한다.
- BloodyMaryPhaseController.StartStage/RevealStage에 묶음 크기를 적용했다. 1·2파트는 한 장씩, 3파트는 두 장씩 0.1초 간격으로 표시한다. 3파트 18장은 총 9묶음이며, 마지막 묶음까지 표시된 뒤 버튼·드래그·10초 타이머를 시작한다.
- Unity 컴파일 오류 없음, 씬의 세 파트 카드 크기 반영을 정적으로 확인했다. 플레이 테스트는 하지 않았다.
- 사용자 확인: 확대된 카드/버튼의 잘림·겹침과 창 경계 드래그를 확인한다. 3파트 진입 시 2→4→…→18장으로 나타나고 등장 중 제거 불가, 마지막 두 장 표시 후 10초 시작인지 확인한다. Retry/최종 완료 정지 및 Play 종료 후 편집값 보존도 확인한다.
