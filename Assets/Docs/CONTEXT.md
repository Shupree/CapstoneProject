## 최신 배틀 구현 (2026-10-20)

- 추가 조정: 퍼즐용 일반/칼 카드 Variant와 종료 버튼을 15% 확대했다(카드 400.2×552). 씬의 이전 크기 오버라이드를 제거해 Variant 크기를 상속한다. 3파트는 0.1초 간격으로 두 장씩 9회 표시하며, 마지막 두 장 표시 후 입력과 10초 타이머를 시작한다. 1·2파트는 한 장씩 유지한다. 컴파일 오류 없음과 세 파트의 확대 크기 반영을 정적으로 확인했으며 플레이 테스트는 하지 않았다.

- 후속 수정: 세 파트 모두 카드 이동 연출을 제거하고 각 최종 위치에 0.1초 간격으로 표시한다(1·2파트 한 장씩, 3파트 두 장씩). 첫 파트는 불규칙한 고정 배치, 2·3파트는 무작위 배치·등장 순서다. 각 파트의 9/12/18개 카드가 모두 표시된 뒤에만 종료 버튼·드래그·10초 타이머를 활성화한다. 이전 생성 시작점·이동 시간 설정은 제거했다. Unity 재컴파일 오류 없음, 게임 테스트 미수행. 다음 사용자 확인은 세 파트 순차 등장·연출 중 입력 차단·등장 완료 기준 제한 시간이다.

- `Battle_Proto`의 1페이즈를 인터넷 이미지 퍼즐에서 큰 화상통화 창의 카드 퍼즐로 변경했다. 새 대치 1초 → 중앙 대사 “갑자기 화면이 이상해졌어.” 2초 → 9장/칼 1개 → 12장/칼 3개 → 18장/칼 5개 순서다. 첫 파트는 고정, 이후는 위치·겹침 순서 무작위다.
- 종료 버튼으로 칼 카드를 제거하며 일반 카드 버튼은 무반응이다. 카드 본체 드래그·맨 앞으로 이동·통화창 내부 경계 제한을 적용했다. 각 파트의 제한 시간은 10초이고, 클릭/드래그/일부 제거로 연장하지 않으며 다음 파트 시작 시만 초기화한다.
- 마지막 파트 완료 시 카드와 타이머를 중단하고 진행을 멈춘다. 기존 2페이즈 연결을 해제하고 완료 이벤트를 확장 지점으로 남겼다. 아래의 인터넷 1페이즈→기존 2페이즈 연결과 무행동 초기화 설명은 과거 구현 기록이다.
- `Assets/Prefab/BloodyMaryCall`에 공통 카드와 4종 Variant를 먼저 만든 뒤 씬에 저장했다. 임시 이미지는 `Assets/Sprite/ProtoType`을 사용하며 프리팹 Image에서 교체할 수 있다. 좌측·하단 UI와 기존 3인 통화 대사는 보존했다. Retry는 새 대치부터 재시작한다.
- Unity 컴파일 오류 0건(기존 Editor 작성 도구의 obsolete API 경고 6건은 유지) 및 저장된 카드 수·칼 수·Variant/버튼/이미지 참조·완료 이벤트 연결 해제를 정적으로 확인했다. 게임 테스트는 수행하지 않았다. 다음 작업은 사용자의 진입 연출·드래그·각 파트 10초·Retry·완료 정지 확인이며, 후속 2페이즈 개편은 별도 요청 시 진행한다.
- 변경 스크립트별 설명, 이미지 교체 방법과 사용자 테스트 순서: [화상통화 카드 1페이즈 안내](BLOODY_MARY_CALL_PHASE.md).

- 같은 날 첫 귀신 조우 예시와 그에 의존한 지침·프로그램 기능 참고를 폐기했다. 첫 만남은 린이 미나의 인터넷 퇴마 소식을 듣고 직접 찾아와 방법을 묻는 것으로 수정했다. 사용자가 수정한 세계관 본문은 보존하고 해당 예시·만남 관련 항목만 동기화했다.

## 플레이 흐름

사이버 퇴마사가 의뢰를 받고 인터넷과 메신저로 괴이를 조사한 뒤, 패턴을 파악하고 상호작용하여 퇴마하는 게임이다. 웹·메일·메신저는 실제 서비스가 아닌 게임 내부 UI다.

현재 블러디 메리 흐름:

**의뢰·화상 통화 → 키워드 검색 → 단서 수집 → 시율에게 조사 결과 전달 → 배틀 통화 → 재시도 연출 → 주인공·메리 통화 → 배틀 테마 전환 → 이미지 판별 1페이즈 → 붉은 문장 어절 수집 2페이즈 → 정답 전송·창 닫기**

- 탐색은 `Assets/Scenes/Explore_Proto.unity`, 배틀은 `Assets/Scenes/Battle_Proto.unity`에서 진행한다. 배틀 씬을 단독 실행하면 조사 완료 상태로 시작한다.
- 1페이즈 완료 시 `ClearedInternetWindow`를 연 뒤 `BloodyMaryPhaseController.onPhaseCompleted`를 호출한다.
- 2페이즈는 `BloodyMaryPhaseTwoController`와 씬에 저장한 문장 4×4·선택 4슬롯으로 구현했다. 네 문장 중 하나를 즉시 표시한 뒤 1초마다 생성하며, 1초 페이드 인·3초 유지한다. `네 / 아기는 / 죽지 / 않았어`를 순서대로 모아 전송하면 창을 닫고 인터넷 아이콘으로 재열기를 차단한다.
- 직접 입력·Enter 전송은 차단한다. 어절 클릭 수집·선택 어절 클릭 삭제·최대 4개·오답 유지·창 닫기 중 시간 정지를 적용했다. 후속 대사·씬 이동·BGM 변경은 추가하지 않았다.
- 2026-10-12 배틀 1·2페이즈 인터넷 창 안쪽 배경을 검은색으로 변경했다. 각 창의 첫 자식 `BattleBlackBackground`에 저장하여 제목·테두리를 유지하고 클릭을 가로채지 않는다. 저장 씬의 색·배치 순서·입력 비차단 설정만 정적으로 확인했으며 게임 테스트는 수행하지 않았다. 다음 사용자 확인: 1페이즈 진입 → 2페이즈 전환 시 검은 배경 유지, 한국어·이미지·버튼의 잘림/겹침과 클릭 동작, Play 종료 후 씬 편집 내용 유지.
- 기존 민서 의뢰 프로토타입은 `Assets/Scenes/CyberExorcistPrototype.unity`에 별도로 남아 있다. 진행 저장·불러오기는 미구현이다.
- 2026-10-12 배틀 게임 오버를 추가했다. 1페이즈는 창을 연 상태에서 무행동 10초(메리 클릭/닫기로 초기화, 닫힌 동안 정지), 2페이즈는 시작부터 전체 30초 제한(닫아도 계속)을 적용한다. 각 실패 연출 → 2초 후 전체 암전 → 고정 손 12개 → 붉은 Signal Lost 화면을 표시한다. Retry는 배틀 테마 직후의 1페이즈로 돌아가며 Exit은 예약된 무동작 버튼이다. 게임 오버 UI는 씬에 저장되어 있다.

- 최신 사용자 요청에 따라 원본을 두 번 연결한 `Assets/SoundEffect/GameOver_Hands_Original_Double.wav`를 생성했다. 첫 복사본 끝의 약한 잔향/여백 0.247초만 줄이고 연결부를 8ms 교차 혼합했다. 두 번째 복사본의 마지막 잔향은 보존했다. 길이 1.745초, 48kHz/24-bit 모노이며 속도·음정·타격 배열을 바꾸지 않았다. 연결부 외 원본 샘플 보존과 클리핑 없음만 확인했으며 직접 청취/게임 연결은 수행하지 않았다.
- 이어서 현재 저장 씬과 편집 모드 컴포넌트의 손 12개·간격 0.07초·마지막 대기 0.4초를 확인했다. 설정상 첫 손 등장부터 붉은 화면까지 1.17초이며 암전 시작부터는 첫 대기 0.07초를 포함해 1.24초다(실제 실행 시간 측정은 하지 않음). 두 번 연결한 원본을 첫 손 등장 기준 1.17초로 자르고 마지막 0.12초를 부드럽게 페이드 아웃한 `Assets/SoundEffect/GameOver_Hands_Final_1170ms.wav`를 생성했다. 페이드 전 원본 샘플 보존·파일 길이·마지막 샘플 0·클리핑 없음을 확인했다. 첫 손 등장에 재생할 파일이며 게임 연결/직접 청취는 수행하지 않았다.
- 2026-10-12 사용자가 정리한 최종 자산 `GameOver_Hands.wav`(1.17초)와 `No_signal.mp3`(7.08초)를 배틀 씬에 연결했다. 첫 손 등장 때 손 효과음, 붉은 화면 전환 때 No_signal을 한 번 재생하며 No_signal 마지막 1초는 샘플 재생 위치 기준 페이드 아웃한다. 손 표시는 하나의 경과 시간 기준으로 계산해 대기 오차 누적을 줄였다. 별도 AudioSource 두 개를 씬에 저장했으며 Retry/비활성화 시 음원을 중단하고 페이드 전 볼륨을 복원한다. 컴파일 오류 없음·음원 참조/길이·1초 설정·반복/자동 재생 비활성·씬 저장·기존 대사/오디오 설정 보존을 정적으로 확인했다. 직접 재생이나 게임 테스트는 하지 않았다. 다음 작업은 사용자의 두 페이즈 실패 시 음원 시작 타이밍·마지막 1초 페이드·재생 도중 Retry·반복 실패 시 볼륨 보존 확인이다.

## 개발 흐름
