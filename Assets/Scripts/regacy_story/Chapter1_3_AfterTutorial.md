# 1챕터 — 도구 설명 이후

(모든 퇴마 도구의 설명을 들은 뒤. 유미나의 방.)

린 : 이걸로 다 봤네. 더 물어볼 건?

유미나 : 음... 일단은 없는 것 같아요!

유미나 : 설명 듣고 나니까 좀 알겠네요. 혼자 책 볼 때는 엄청 헷갈렸는데.

린 : 막상 쓸 때 헷갈리면 다시 확인해. 아무거나 누르지 말고.

유미나 : 네! 메모도 해 놨어요, 헤헤.

나레이션 : 린은 화면을 한번 훑어보더니 자리에서 일어났다.

린 : 그럼 난 간다.

유미나 : 어? 벌써요?

린 : 알려줄 건 다 알려줬고. 들어온 의뢰도 없다며.

유미나 : 그건 그렇지만...

나레이션 : 그 때, 메일 알림음이 울렸다.

유미나 : 어?

나레이션 : 화면 한쪽에 새 메일 알림이 떠 있었다.

유미나 : 잠깐만요. 이거... 의뢰인데요?

린 : ...타이밍 한번 좋네.

나레이션 : 메일 제목을 확인하고 린을 돌아봤다. 린은 벌써 귀찮다는 표정이었다.

유미나 : 린 씨.

린 : 왜.

유미나 : 이 의뢰까지만 같이 봐 주시면 안 돼요?

린 : 방금 다 알려줬잖아.

유미나 : 아는 거랑 직접 하는 건 다르잖아요. 첫 의뢰인데!

유미나 : 옆에서 조금만 봐 주세요. 네?

나레이션 : 나는 린을 빤히 올려다봤다.

린 : ...그렇게 쳐다보지 마.

유미나 : 그럼 도와주시는 거예요?

린 : 하... 알았어. 일단 내용부터 봐.

유미나 : 진짜요? 감사합니다!

나레이션 : 린이 다시 자리를 잡았다. 나는 얼른 마우스를 쥐었다.

린 : 네가 하는 거야. 난 옆에서 봐 주는 거고.

유미나 : 네! 막히면 물어봐도 되죠?

린 : ...그러려고 남는 거잖아.

유미나 : 헤헤. 그럼 열어 볼게요!

(메일을 열어 내용을 확인한다. 1챕터 의뢰 시작.)
