# 1챕터 — 도입

나레이션 : 2개월 뒤..

나레이션 : 나는 개발자 일을 그만두고, 퇴마사가 되기 위한 준비를 시작했다.

유미나 : 좋아. 일단 다 만들었다!

나레이션 : 가장 먼저 만든 건 퇴마 프로그램. 부모님께 받은 의식서에서 자주 쓰인다는 의식들을 골라 컴퓨터에서 흉내 내 봤다.

나레이션 : 화면에 나란히 놓인 프로그램들을 보니 제법 그럴듯했다.

유미나 : ...그런데 이게 진짜 통하려나?

나레이션 : 책에 나온 걸 최대한 따라 하기는 했지만, 사실 진짜 효과가 있는 지는 확인해 본 적은 없었다.

나레이션 : 그보다 더 큰 문제는, 내가 각 의식의 정확한 역할을 모르는 것이었다.

유미나 : 이걸 먼저 쓰라는 건가? 아니면 이쪽부터...?

유미나 : 으.. 이게 한국어가 맞긴 한건가..?

나레이션 : 그 때, 현관에서 초인종 소리가 들렸다.

유미나 : 음? 이 시간에 누구지?

유미나 : 네\~ 나가요\~

나레이션 : 문을 열자 모르는 여자가 서 있었다.

낯선 사람 : 네가 유미나야?

유미나 : 엇, 네. 맞는데요...?

낯선 사람 : 흠. 좀 맹하게 생겼네.

유미나 : 네...? 아니, 누구신데 갑자기 그러세요!

린 : 채 린. 그냥 린이라고 불러.

린 : 유 사범님 부탁으로 왔어. 너 퇴마 일 시작한다며?

유미나 : 아! 아빠가 도와주실 분을 보내 준다고 했었어요.

유미나 : 아, 잠깐, 채 린이면... 퇴마 업계에서는 모르는 사람이 없다는 그...??

린 : 뭐, 그런 건 됐고, 뭐부터 도와주면 돼?

유미나 : 아... 일단 들어오세요.

나레이션 : 생각보다 훨씬 더 무뚝뚝한 사람이었다. 인사말을 더 준비할 필요는 없을 것 같았다.

나레이션 : 나는 린을 책상 앞으로 안내했다.

유미나 : 흐흠, 제가 인터넷 귀신을 볼 수 있다는 건 들으셨죠?

린 : 응. 직접 성불도 시켰다며.

유미나 : 네! 그래서 앞으로 쓸 도구도 만들어 봤어요.

린 : 도구?

유미나 : 퇴마 프로그램이요. 여기 있는 의식들을 컴퓨터에서도 할 수 있게 만든 거예요.

나레이션 : 의식서를 린 쪽으로 밀어 놓고, 화면의 프로그램들을 가리켰다.

유미나 : 자주 쓰는 것부터 골랐어요. 보시면 아시겠지만 나름 책이랑 비슷하게...

린 : 써 보긴 했고?

유미나 : ...아직이요.

린 : 그럼 작동하는지도 모르겠네.

유미나 : 그, 그렇죠. 일단 흉내는 냈는데...

유미나 : 사실 어떤 상황에서 뭘 써야 하는지도 좀 헷갈려요.

린 : ...만들기 전에 물어보지 그랬어.

유미나 : 만들 때는 알 것 같았거든요...

나레이션 : 린은 펼쳐진 의식서와 화면을 번갈아 봤다.

린 : 뭐, 됐어. 어떤 의식인지부터 확인하면 되니까.

유미나 : 그럼 사용법도 알려 주실 수 있어요?

린 : 그거 알려 주러 왔잖아. 하나씩 보여 줘.

유미나 : 네! 여기 있는 것들이에요.

(퇴마 프로그램 UI로 전환. 도구를 선택해 설명을 듣는 튜토리얼 시작.)
