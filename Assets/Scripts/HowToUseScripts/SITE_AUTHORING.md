# 탐색 브라우저 페이지 제작

## Lounge X 게시글 만들기

1. **Tools → 사이트 제작 → 템플릿 제작 에디터**에서 이름에 `Lounge X 게시글`을 입력하고 **새 템플릿 만들기**를 누른다. 열린 프리팹에서 루트 Image 색으로 배경색을 정하거나 **공용 이미지 추가**로 로고를 배치한다.
2. 요소 이름과 종류를 정하고 **슬롯 추가**를 누른다. `제목`과 `작성자`는 Text로, `본문`은 Body로 만든다. 슬롯은 처음에 중앙에 놓인다. 목록에서 하나씩 선택하고 Scene의 Rect Tool(T)로 위치와 크기를 정한다. 본문 슬롯의 사각형은 스크롤로 읽을 수 있는 범위다. Ctrl+S로 저장한다.
3. **Tools → 사이트 제작 → 페이지 제작 에디터**에서 **새 페이지**를 누르고 방금 만든 프리팹을 템플릿 필드로 끌어온다. 주소를 `lounge.local/post/photo`로 입력하고 제목과 작성자를 채운다. 본문에는 **+ 문단**, **+ 이미지**, **+ 링크**, **+ UI 프리팹**으로 블록을 넣는다. 화살표는 표시 순서를 바꾼다.
4. 이미지 블록에 Project 창의 Sprite를 넣는다. 사진에서 조사할 부분을 드래그하고 번호가 표시된 영역에 이벤트 ID를 입력한다. 예를 들어 `photo_mirror`를 입력하면 게임에서 해당 영역을 처음 클릭했을 때 단서 획득 문구가 표시된다. 영역을 추가로 그리거나 X·Y·너비·높이를 수정하고 **페이지 저장**을 누른다. Image 슬롯에서도 같은 방법으로 지정한다.
5. **새 페이지**로 같은 템플릿을 사용하는 `lounge.local/post/index`를 만든다. 본문에 링크를 추가하고 문구를 ‘사진이 올라온 원글’로 쓴 뒤 목적지 목록에서 `lounge.local/post/photo`를 골라 저장한다.
6. 탐색 씬 인터넷 주소창에 `lounge.local/post/index`를 입력하고 Enter를 누른다. 링크로 원글에 들어가 조사 영역을 클릭한다. 뒤로·앞으로 버튼은 기존 페이지와 같은 방문 기록을 사용한다.

## 수정과 저장

페이지 제작 창에서 **사이트 미리보기**를 누르면 현재 입력한 내용이 별도 창에 표시된다. 긴 본문은 창 위의 슬라이더로 내릴 수 있다. 내용을 수정한 뒤 같은 버튼을 다시 누르면 화면이 갱신된다. 링크 이동과 단서 획득은 게임에서 확인한다.

- 기존 템플릿은 템플릿 창의 **기존 템플릿 → 프리팹 편집 열기**, 기존 페이지는 페이지 창의 **저장한 페이지 열기**에서 연다. 같은 슬롯을 선택해 이름과 위치를 바꾸면 ID가 유지된다. 삭제 후 새로 만든 슬롯에는 새 ID가 생긴다. Hierarchy에서 슬롯을 복제해 중복 경고가 뜨면 복제본에 새 ID를 부여한다.
- 공용 요소와 슬롯 배치는 중첩 프리팹을 통해 반영된다. 슬롯을 추가하거나 삭제했다면 사용하는 페이지를 다시 열고 해당 슬롯 내용을 확인한 뒤 저장한다. 페이지 주소 변경 후에도 링크의 목적지 ID는 유지된다.
- 좌표 원점은 Sprite의 왼쪽 위다. 모든 값은 이미지 크기를 1로 본 비율이다. 영역이 겹치면 앞 번호를 먼저 처리한다. 블록 순서를 바꾸면 그 이미지에 소속된 영역도 함께 이동한다.
- 조사 ID는 기존 사건의 `inspect/` 뒤에 오는 키와 같은 공간을 사용한다. 예를 들어 `taboo`는 서연의 금지어 질문 조건에 영향을 준다. 독립된 단서에는 별도 ID를 사용한다. 단서 상태는 현재 탐색 씬의 `ExploreLinkCase`가 관리한다.
- 주소는 기존 사건 페이지 35개와 새 페이지 전체에서 고유해야 한다. 저장 오류에 표시되는 슬롯·블록·영역 번호에서 참조를 수정한다.

| 항목 | 프로젝트 내 위치 |
| --- | --- |
| 템플릿 프리팹 | `Assets/Explore_Proto/SiteAuthoring/Templates/<이름>.prefab` |
| 페이지 JSON | `Assets/Explore_Proto/SiteAuthoring/Pages/<페이지 ID>.json` |
| 탐색 씬에 연결된 페이지 UI | `Assets/Explore_Proto/SiteAuthoring/BrowserPages.prefab` |

페이지 저장 시 JSON과 페이지 UI를 함께 갱신한다. 편집용 에셋 키는 GUID와 서브에셋 ID로 이루어지며, 빌드에서는 미리 배치한 UI의 직렬화된 Sprite·프리팹·JSON 참조를 사용한다. 이미지와 UI 프리팹은 프로젝트의 기존 폴더에서 선택할 수 있다.
