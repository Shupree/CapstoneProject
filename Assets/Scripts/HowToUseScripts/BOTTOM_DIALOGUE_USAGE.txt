하단 대화창 사용·확장 가이드
갱신: 2026-10-18

목적
- 이 문서는 다른 팀원이나 AI가 기존 하단 대화창을 재사용할 때의 연결 방법과 데이터 계약을 설명한다.
- 작업 전 프로젝트 루트의 AGENTS.md, Docs/CONTEXT.md,
  Assets/Scripts/HowToUseScripts/DIALOGUE_CSV_GUIDE.md를 읽고 실제 코드·프리팹·씬 상태를 확인한다.
- 이 문서는 현재 구현의 설명이다. 실제 동작은 아래 스크립트와 저장된 프리팹을 기준으로 판단한다.

1. 구현 파일과 책임
- Assets/Prefabs/BottomDialogueSystem.prefab
  화면 암전, 좌우 Image, 이름·대사 TMP 텍스트, 화면 전체 클릭 Button을 미리 가진 uGUI 프리팹.
- Assets/Explore_Proto/Scripts/BottomDialogueController.cs
  SceneID로 대사를 요청하고 현재 줄, 다음 줄, 종료 및 이벤트를 관리한다.
- Assets/Explore_Proto/Scripts/BottomDialogueView.cs
  저장된 UI 오브젝트의 텍스트·Sprite·밝기·표시 여부만 바꾼다.
- Assets/Explore_Proto/Scripts/BottomDialoguePortraitLibrary.cs
  CSV의 Image ID를 Sprite로, SpeakerID를 좌우 위치와 기본 Image ID로 바꾼다.
- Assets/Scripts/DialogueReader/DialogueCsvReader.cs
  CSV를 파싱해 SceneID별 Order 순서의 DialogueLine 목록을 제공한다.
- Assets/Explore_Proto/Data/BottomDialoguePortraitLibrary.asset
  현재 이미지·화자 연결 데이터. 새 인물을 쓰면 이 에셋에 등록한다.
- Assets/Explore_Proto/Data/BottomDialogue_Reference.csv
  린/유미나 두 줄로 된 연결 예시. SceneID는 BottomDialogue_Reference.

2. 씬에 연결하는 방법
- 현재 Assets/Scenes/Explore_Proto.unity와 Assets/Scenes/Battle_Proto.unity의
  ExploreProtoCanvas > BottomDialogueSystem에 프리팹 인스턴스가 이미 있다.
- 다른 씬에서는 Canvas 아래에 프리팹을 배치하고 EventSystem이 있는지 확인한다.
- 프리팹의 루트 GameObject는 활성 상태, 자식 VisualRoot는 초기 비활성 상태로 둔다.
- 루트의 DialogueCsvReader > Dialogue Csv에 사용할 CSV TextAsset을 연결한다.
- BottomDialogueController의 Dialogue Reader, View, Portrait Library 참조가 연결되어야 한다.
  기존 프리팹에는 예시 CSV와 기본 라이브러리가 연결되어 있다.
- 원하는 게임 트리거가 발생할 때 아래 공개 메서드를 호출한다. 현재 두 씬에는
  자동 시작 트리거가 연결되어 있지 않다.

3. 공개 호출 API
- bool StartDialogue(string sceneId): 해당 SceneID의 첫 줄을 표시한다.
  성공하면 true, 참조/CSV/SceneID가 잘못되면 false와 Console 오류를 반환한다.
- void Play(string sceneId): Button On Click 또는 UnityEvent의 문자열 인자로
  시작할 때 쓰는 래퍼. 내부에서 StartDialogue를 호출한다.
- void NextDialogue(): 다음 줄로 진행한다. 마지막 줄 이후 호출하면 창을 닫고
  On Dialogue Completed에 완료한 SceneID를 보낸다.
- void StopDialogue(): 중간 종료한다. 완료 이벤트는 보내지 않는다.
- IsPlaying, CurrentSceneId: 현재 실행 여부와 대화 묶음 ID를 읽는다.

코드에서 시작하는 예:
  [SerializeField] private BottomDialogueController bottomDialogue;
  ...
  if (!bottomDialogue.StartDialogue("BottomDialogue_Reference"))
      Debug.LogWarning("하단 대화를 시작하지 못했습니다.");

Inspector에서 시작하는 예:
  트리거의 Button On Click에 Hierarchy의 BottomDialogueSystem을 넣고
  BottomDialogueController > Play(string)을 선택한 다음,
  문자열 칸에 BottomDialogue_Reference를 입력한다.

4. CSV 데이터 계약
- 헤더: SceneID,Order,SpeakerID,Dialogue,Image,EventID
- SceneID는 Unity 씬 이름이 아니라 CSV 안의 대화 묶음 ID다.
  한 CSV에 여러 SceneID를 넣고 시작할 때 ID를 골라 요청할 수 있다.
- 같은 SceneID의 Order는 1부터 중복·누락 없이 증가한다.
  다음 SceneID에서는 Order를 다시 1부터 시작한다.
- SpeakerID는 화면의 이름으로 표시되고, PortraitLibrary의 Speakers에서
  좌우 위치도 찾는다. 대소문자와 이름 안쪽 공백이 정확히 같아야 한다.
- Image는 Sprite 파일 경로가 아니라 PortraitLibrary의 Portraits에 등록한
  Image ID다. 비워 두면 해당 위치의 직전 Sprite가 유지된다.
- EventID는 필요할 때 외부 진행 코드가 해석할 문자열이다.
  CSV 리더나 하단 대화창이 임의의 게임 이벤트를 자동 실행하지 않는다.

예:
  SceneID,Order,SpeakerID,Dialogue,Image,EventID
  BottomDialogue_Reference,1,린,너가 유미나야?,SubCharacter_01,
  BottomDialogue_Reference,2,유미나,네.. 맞는데요..?,MainCharacter_01,

5. 새 화자·표정 추가
- PortraitLibrary.asset의 Portraits에 Image ID와 Sprite를 먼저 등록한다.
- 같은 에셋의 Speakers에 Speaker ID, Left 또는 Right,
  Default Image ID를 등록한다. CSV의 SpeakerID와 Image 표기를 일치시킨다.
- 시작 전에 Controller가 해당 SceneID의 줄을 훑어 등장하는 화자의 좌우 첫 이미지를 준비한다.
  해당 화자의 Image가 비어 있으면 등록된 기본 이미지를 사용한다.
- 각 줄에서 Image가 유효하면 현재 화자의 위치에만 적용한다.
  등록되지 않은 SpeakerID나 Image ID는 Console 경고를 남긴다.
- 양쪽 인물은 대화 중 동시에 보일 수 있다. 현재 화자는 원래 밝기,
  반대쪽은 RGB 50% 밝기로 표시된다.

6. 이벤트와 UI 동작
- VisualRoot를 보일 때 프리팹 루트를 Canvas의 마지막 자식으로 올린다.
  저장된 Image/TMP 오브젝트를 갱신하며 런타임에 UI를 생성하지 않는다.
- ScreenDimmer는 검정 알파 0.4, DialogueBar/NameBar는 검정 알파 0.8이다.
- VisualRoot의 AdvanceClickArea(Button)가 화면 클릭을 받아
  Controller.NextDialogue()를 호출한다.
- On Event Requested: EventID가 있는 줄을 표시할 때 그 문자열을 전달한다.
- On Dialogue Completed: 마지막 줄 다음 클릭으로 정상 종료할 때
  완료한 SceneID를 전달한다. 두 UnityEvent는 필요할 때 Inspector에서 연결한다.
- 텍스트 배치, 이미지 크기, 색을 바꾸려면 프리팹 또는 씬 인스턴스의
  저장된 UI를 편집한다. 기존 씬을 빌더 코드로 재생성하지 않는다.

7. 변경 시 확인할 사항
- CSV를 바꾸었다면 DialogueCsvReader의 Dialogue Csv 참조와 SceneID를 확인한다.
  CSV 형식 오류 또는 없는 SceneID는 시작 실패 원인이 된다.
- 이미지가 비어 보이면 PortraitLibrary의 ID·Sprite·Speaker 위치를 확인한다.
- 이름은 나오지만 양쪽이 모두 어두우면 SpeakerID가 등록되지 않았는지 확인한다.
- 다른 씬으로 옮길 때는 프리팹, Canvas, EventSystem, CSV,
  PortraitLibrary 연결을 확인한다.
- 게임 플레이 확인은 사용자가 수행한다. 시작 전 숨김, 한국어·텍스트 잘림,
  두 이미지의 밝기 전환, 클릭마다 한 줄 진행, 마지막 클릭 종료,
  다른 UI와의 겹침·입력, 씬 재열기 후 편집 내용 유지를 확인한다.
