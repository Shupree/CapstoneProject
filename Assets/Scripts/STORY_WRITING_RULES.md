# 스토리 문서 역할과 작성 규칙

## 문서 역할

| 문서 | 역할 |
| --- | --- |
| [Universe.md](Universe.md) | 전체 세계관 설정 |
| [Char_profile.md](Char_profile.md) | 인물 성격 및 배경 설정 |
| [story_index.md](story_index.md) | 각 파트별 스토리 요약. 각 파트의 스토리 설정 MD에 적힌 사건을 요약한다. |
| 각 파트의 Story_Settings.md | 해당 파트의 사건 설정, 엑스트라 설정, 스토리 진행 |
| 각 파트의 세부 스크립트 MD | 장면별 대사·나레이션·연출. 세부 파트마다 파일을 나눈다. |
| 각 파트의 스크립트 CSV | 사용자가 변환을 요청한 MD 스크립트를 [CSV 형식](Dialogue_CSV_Format.md)에 맞춘 결과물 |

## 폴더 구조

```text
Assets/Scripts/
  Universe.md
  Char_profile.md
  story_index.md
  STORY_WRITING_RULES.md
  Dialogue_CSV_Format.md
  Story_Parts/
    <파트명>/
      Story_Settings.md
      01_<세부파트>.md
      02_<세부파트>.md
      01_<세부파트>.csv  ← 변환 요청 시 생성
      02_<세부파트>.csv  ← 변환 요청 시 생성
```

파트나 세부 장면이 아직 정해지지 않았다면 빈 스크립트나 CSV를 미리 만들지 않는다. 린의 첫 만남 폴더는 배치 시점 미정이며 폴더 순서로 챕터를 확정하지 않는다.

## 스크립트 작성 순서와 참고 범위

1. 전체 설정은 Universe와 Char_profile, 이야기 흐름은 story_index를 확인한다.
2. 작업할 파트의 Story_Settings.md에서 사건·엑스트라·진행 조건을 확인한다. 새로 합의한 사건은 이 설정 파일에 정리한다.
3. 새 스크립트를 작성할 때 다른 세부 스크립트는 참고하지 않는다. Prologue_Opening_Cutscene 같은 기존 대본, 옛 대사 예시, 기존 CSV를 읽어 다음 이야기를 추론하지 않는다. Char_profile의 예시 근거 링크도 따라 읽지 않는다. story_index와 해당 파트의 설정에 적힌 흐름을 기준으로 작성한다.
4. 스크립트는 MD로 먼저 작성하고 세부 파트마다 파일을 구분한다. 수정안을 먼저 대화에서 보여주고, 사용자가 반영을 요청하면 저장한다.
5. 사용자가 특정 스크립트의 수정을 요청하면 그 대상 파일을 읽고 편집한다. CSV 변환 요청 때도 변환 대상 MD를 읽는다. 이는 다른 스크립트를 이야기 참고 자료로 읽는 것과 구분한다.
6. CSV는 사용자가 요청했을 때만 만든다. 대상 MD의 내용을 임의로 개작하지 않고 같은 폴더에 같은 기본 이름으로 저장한다. 이후 MD 수정만으로 CSV가 자동 갱신되었다고 간주하지 않는다.

유미나의 내면은 ‘나레이션’으로 표기하고 괄호 없는 1인칭 서술로 작성한다. 설정을 한 번에 나열하지 않고 장면에 필요한 만큼 드러낸다. 확정·제안·미정을 구분한다.

## Universe·Char_profile 갱신 규칙

- 사용자가 Universe 갱신을 명시적으로 요청하지 않으면 Universe의 설정을 수정하지 않는다.
- Char_profile도 동일하다. 인물 설정 갱신 요청 없이 스크립트에 맞춰 자동 수정하지 않는다.
- 작성하려는 스크립트가 두 문서와 충돌하면 해당 설정과 충돌 내용을 짚고, 해당 문서를 갱신할지 사용자에게 묻는다. 답변 전에 충돌을 새 확정 설정으로 반영하지 않는다.
- 스크립트 작성이나 반영 요청 자체를 전체 설정 갱신 요청으로 해석하지 않는다.

## story_index 갱신 규칙

- 각 Story_Parts/<파트>/Story_Settings.md의 사건과 진행을 요약해서 작성한다.
- 모든 세부 스크립트를 읽거나 CSV를 역으로 분석해 줄거리를 만들지 않는다.
- 새 사건을 스크립트에서 임의 추출하지 않는다. 합의된 사건을 먼저 Story_Settings.md에 정리하고 그 내용을 요약한다.
- 대사 전문은 포함하지 않는다. 파트 순서, 핵심 사건, 연결, 미정 사항을 중심으로 쓴다.
- 개별 설정 문서와 요약이 충돌하면 설정 문서를 기준으로 요약을 바로잡되, 전체 세계관·인물 설정과의 충돌은 사용자에게 확인한다.

기존 regacy_story는 보관용이며 새 스크립트의 참고 대상으로 사용하지 않는다.
