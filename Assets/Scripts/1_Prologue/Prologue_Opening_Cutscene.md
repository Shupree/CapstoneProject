# 프롤로그 — 화면 너머의 시선

## 1\. 오프닝 — 사라지지 않는 사진

(오프닝은 네 컷의 만화 이미지로 연출한다. 이후는 배경 이미지, 인물 이미지와 표정 변경, 대화창으로 진행한다.)

(더빙이나 영상 동작을 전제로 하지 않는다. 대사와 나레이션은 텍스트로 표시하며, 상황 전환과 주요 행동은 효과음 없이도 이해되도록 나레이션으로 전달한다.)

### 컷 01 — 고쳤는데

(모니터 앞에서 작업 중인 유미나. 화면에는 코드와 사이트가 나란히 열려 있다. 사이트 한쪽에는 어두운 복도 사진이 떠 있다. 복도 끝의 문은 조금 열려 있지만 사람은 보이지 않는다.)

유미나 : ……왜 아직도 뜨지?

나레이션 : 나는 모니터 앞에 앉아 의뢰를 처리하고 있었다.

나레이션 : 사이트에서 자꾸만 나타나는 사진을 없애 달라는 의뢰였다.

나레이션 : ...벌써 코드를 몇 번이나 고쳤지만, 사진은 어째선지 그대로였다.

유미나 : 으.. 간단한 건줄 알고 좋아했는데..

### 컷 02 — 이상한 변화

(수정 후 새로고침한 모니터. 같은 복도 사진의 문틈에 얼굴 반쪽이 보인다. 마우스 위의 손이 멈춘다.)

나레이션 : 페이지를 한 번 더 새로고침하다가 손이 멈췄다.

유미나 : ……저기 사람이 있었나?

### 컷 03 — 가려진 사진

(유미나가 다른 작업 창으로 사진을 덮는다. 얼굴은 완전히 가려지고 복도 사진 가장자리만 남는다.)

나레이션 : 나는 작업창으로 사진을 가려두고 다시 한번 코드를 확인했다.

나레이션 : 그 때...

컷 04 — 이쪽을 보는 얼굴

(앞 컷과 같은 화면 구도. 가린 창의 가장자리 밖으로 얼굴이 나와 유미나를 바라본다. 대사와 효과음 없이 잠시 유지한다.)

(짧은 암전. 만화 컷신 종료.)

## 2\. 미연시 연출 — 정상으로 돌아온 사이트

(배경: 밤의 유미나 작업실. 모니터에는 정상적인 사이트가 떠 있다. 인물: 놀라 굳은 유미나. 하단 대화창 표시.)

유미나 : 우와아아앗!!?!

나레이션 : 책상에서 떨어진 채 모니터를 바라봤다. 어느새 사진은 사라지고 평범한 사이트 화면만 남아 있었다.

유미나 : ……뭐야.

유미나 : 방금, 분명히…….

나레이션 : 한참 망설이다 마우스에 손을 뻗어 페이지를 다시 열었다.

나레이션 : 다시 열어 본 페이지는 멀쩡했다.

유미나 : 고쳐졌네, 자동으로...

(유미나 표정: 당혹. 잠시 화면을 살피다가 숨을 내쉰다.)

유미나 : 작업 완료라고 보내도 되나, 이거.

나레이션 : 메일 창을 열려던 손이 멈췄다. 방금 그 얼굴이 자꾸 떠올랐다.

유미나 : ……진짜 귀신이었나?

유미나 : 엄마한테 물어보자. 이런 일은 나보다 훨씬 잘 알 테니까.

나레이션 : 휴대전화를 집어 엄마에게 전화를 걸었다. 잠시 뒤 엄마가 전화를 받았다.

## 3\. 미연시 연출 — 엄마와의 통화

(작업실 배경 유지. 엄마의 인물 이미지는 띄우지 않고, 화자 이름과 대사 텍스트로 통화를 표현한다.)

엄마 : 미나야? 이 시간에 무슨 일이야?

유미나 : 엄마, 귀신이 컴퓨터 안에서도 보일 수 있어?

엄마 : 컴퓨터? 왜, 무슨 일 있었어?

유미나 : 일하다가 어떤 사이트에서 이상한 걸 봤어. 사진 속에 있던 게 나를 보고 있었거든.

엄마 : ……너한테 보였다고? 괜찮아? 다친 데는 없고?

유미나 : 응. 지금은 사이트도 멀쩡해. 귀신 같은 건 엄마가 잘 아니까 물어보려고.

엄마 : 다친 데 없다니 다행이다. 요즘 인터넷에서도 그런 일이 생겨.

유미나 : 그럼 그런 것도 퇴마 의뢰가 와?

엄마 : 응. 그런데 하던 의식으로는 있는지 알아내기도 어렵고, 퇴마도 통하질 않아.

유미나 : ……엄마랑 아빠도 못 해?

엄마 : 우리뿐이겠니. 다른 퇴마사들도 마찬가지야.

(유미나 표정: 생각에 잠김. 짧은 침묵.)

엄마 : 미나야?

유미나 : 아, 응. 듣고 있어.

엄마 : 네가 얼마나 보고 싶어 했는데…… 하필 혼자 있을 때 이런 걸 봤네.

유미나 : 그러게. 좀 덜 무서운 걸로 시작했으면 좋았을 텐데.

엄마 : 오늘은 그만하고 쉬어. 놀란 김에 밤새우지 말고.

(유미나 표정: 작은 웃음.)

유미나 : 엄마, 나 원래 자려고 했어.

엄마 : 그러다 일 하나만 더 한다고 앉았지?

유미나 : ……어떻게 알았어?

엄마 : 네가 늘 그렇지. 얼른 쉬어.

유미나 : 응. 엄마도 잘 자.

## 4\. 미연시 연출 — 다시 꺼낸 꿈

(작업실 배경 유지. 유미나 표정: 생각에 잠김.)

나레이션 : 통화를 마치고 휴대전화 화면을 껐다. 전화기를 내려놓고도 엄마의 말을 곱씹었다.

유미나 : ……근데 인터넷에서는 보인다고?

나레이션 : 귀신이 보이지 않아서 포기했던 꿈이었다.

유미나 : 그럼 여기서는…… 나도 퇴마사가 될 수 있잖아.

(유미나 표정: 조심스러운 기대.)

유미나 속마음 : (이거 잘하면, 아버지도 좀 다르게 봐 주시려나.)

(잠깐 시선을 내렸다가 다시 모니터를 본다. 유미나 표정: 의욕.)

유미나 : 좋아. 일단 뭘 준비해야 하지?

유미나 : 의식서부터 다시 봐야겠다. 컴퓨터에서도 할 수 있는 방법이 있을지…….

(유미나 표정: 잠깐 긴장.)

나레이션 : 마우스를 잡으려다 어두운 모니터 가장자리가 눈에 들어왔다. 방금 그 얼굴이 떠올라 손이 멈췄다.

유미나 : ……불부터 켜고.

(배경을 불 켜진 작업실로 변경한다. 유미나 표정: 조금 편안해진 웃음.)

나레이션 : 자리에서 일어나 방 불을 켰다. 환해진 방을 둘러보고 나니 조금 마음이 놓였다.

나레이션 : 무섭기는 했다. 그래도 이번에는 의자를 책상 앞으로 당겼다.

유미나 : 사이버 퇴마사라…….

유미나 : 해 보자. 이번엔.

(천천히 암전. 이후 프로그램 제작과 준비 장면으로 연결한다. 이 시점에는 퇴마 경험도, 완성된 퇴마 프로그램도 없다.)
