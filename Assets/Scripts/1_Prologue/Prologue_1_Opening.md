# 1\_Prologue — 게임 시작

(어릴 적 집 모습)

나레이션 : ...

나레이션 : 어릴 적 집이 보인다. 그 곳에는 어릴 적의 나와 부모님이 사진을 보고 있었다.

어린 미나 : 엄마!! 이 사진은 뭐야\~?

엄마 : 사진? 아\~ 우리 미나 태어나기 전에, 아빠가 엄\~청 큰 귀신을 잡았을 때야.

어린 미나 : 와\~ 아빠가 잡았어?

아빠 : 그럼! 아빠가 얼마나 센데\~

엄마 : 어이구, 딸 앞이라고 또 자랑한다.

아빠 : 하하! 나중엔 미나가 아빠보다 더 잘할 텐데, 지금이라도 자랑해야지.

어린 미나 : 우와! 나도 아빠처럼 될 수 있어?

아빠 : 물론이지. 퇴마사 가문 중에서는 우리 유 가문이 최고거든.

나레이션 : ...

(화면 전환. 방 한가운데 사람이 누워 있다. 어린 미나는 아빠의 옆에 서 있다.)

아빠 : 오늘은 아빠가 일하는 걸 보여 줄게.

어린 미나 : 저 아저씨, 아픈 거야?

아빠 : 귀신이 붙어서 그런 거야. 그 귀신을 떼어 내면 괜찮아질 거란다.

어린 미나 : ……아빠, 무서워.

아빠 : 괜찮아, 아빠가 옆에 있잖니. 잘 보고 있으렴.

나레이션 : 아빠가 이런저런 물건을 주위에 두고, 주문을 외기 시작했다.

나레이션 : 그러자 누워 있던 사람의 몸이 크게 들썩인다. 벌어지는 입에서 거친 숨소리가 새어 나온다.

나레이션 : 아빠는 그 '숨'을 잡는 듯 하더니, 내 쪽으로 손을 펼쳤다.

아빠 : 자, 나왔다. 보이니?

어린 미나 : …어디에?

아빠 : 여기. 아빠 손 바로 앞에 있잖니.

어린 미나 : 음...아무것도 없는데.

나레이션 : 아빠의 손이 잠시 멈췄다.

아빠 : …조금 더 가까이 와서 볼래?

나레이션 : 나는 한 걸음 더 다가갔다.

어린 미나 : ...

어린 미나 : 그래도 안 보여.

(화면이 어두워진다)

나레이션 : ...

나레이션 : 어두운 공간 속에서 여러 사람의 목소리가 들린다.

목소리 1 : 유 가문 딸 말이야. 아직도 귀신을 못 본다며?

목소리 2 : 영력이 그렇게 강하다더니…… 잘못 본 거 아니야?

목소리 1 : 귀신도 못 보면서 무슨 퇴마를 하겠어.

목소리 3 : 쉿. 애 듣겠어.

목소리 2 : 틀린 말도 아닌데, 뭐.

목소리 1 : ...

목소리 1 : 그 이름난 유 가문도 이제 끝이네.

(화면 전환, 미나의 방)

나레이션 : ...나는 잠에서 깨어났다.

유미나 : …으음

유미나 : …요새 꿈을 자주 꾸네.

나레이션 : 나는 눈가를 문지르며 시계를 확인한다. 시계는 오전 11시 48분을 가리키고 있었다.

유미나 : ……

유미나 : 뭐?! 벌써 점심이잖아!

나레이션 : 이불을 걷어차고 일어났다. 급하게 슬리퍼를 찾다가 침대 밑에서 끌어냈다.

유미나 : 분명 아홉 시에 알람 맞췄는데…… 껐네. 그것도 내가.

나레이션 : 배에서 꼬르륵 소리가 난다.

유미나 : 에휴... 그래, 일단 밥부터 먹자. 

나레이션 : 나는 퇴마사의 꿈을 접고 프리랜서 개발자가 되었다.

나레이션 : 귀신을 못 보는 퇴마사 같은 게 가능할리는 없었으니 말이다.

나레이션 : 사실, 나는 지금의 삶이 생각 이상으로 좋다.

나레이션 : 개발 일도 적성에 맞는 것 같고, 오늘 같이 늦잠을 자도 그리 치명적이지는 않다.

나레이션 : ...그래도 어제는 일찍 잘 걸 그랬다.

나레이션 : ...

나레이션 : 나는 식사를 마치고 자리에 앉아 컴퓨터를 켰다.

유미나 : 자, 오늘은 어떤 외주가 들어왔으려나\~

유미나 : 메일부터 확인해 볼까\~?

(게임 데스크톱 화면으로 전환. 메일 확인 튜토리얼 시작.)
