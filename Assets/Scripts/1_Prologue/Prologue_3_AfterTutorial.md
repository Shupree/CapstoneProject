# 1\_Prologue — 튜토리얼 이후

(유미나의 방. 튜토리얼에서 만난 귀신이 사라진 뒤.)

유미나 : ...진짜 갔네.

나레이션 : 책을 내려놓고 다시 화면을 들여다봤다. 아무것도 보이지 않았다.

유미나 : 내가 귀신을 다 보네. 그것도 컴퓨터에서.

나레이션 : 잠시 빈 화면을 바라보다가 휴대전화를 집어 들었다.

(어머니에게 전화를 건다. 잠시 연결음이 들린다.)

엄마 : 응, 미나야. 웬일이야?

유미나 : 엄마, 혹시 인터넷에도 귀신이 살아?

엄마 : ...인터넷?

유미나 : 응. 사이트 같은 데 말이야.

엄마 : 최근에 밝혀진 일인데, 그건 어떻게 알았니?

유미나 : 어? 진짜 있는 거야?

엄마 : 안 그래도 요즘 그것 때문에 골치가 아파. 이상한 일을 겪었다는 사람은 있는데, 우리가 어떻게 해 줄 수가 없으니.

유미나 : 엄마랑 아빠도 못 해?

엄마 : 우리가 하는 의식은 현실의 물건이나 사람한테 쓰는 거잖니. 인터넷에 있는 것들한테는 영향을 주지 못하더구나.

유미나 : 그럼 귀신이 있는 사이트를 알아도 못 잡는 거야?

엄마 : 응. 게다가 의식 중에는 귀신을 감지하는 의식도 포함되어 있는데, 의식 자체가 안 통하니 확인하는 것부터가 어려워.

유미나 : ...그렇구나.

엄마 : 그런데 갑자기 그건 왜? 네가 맡은 일에도 무슨 문제 있니?

유미나 : 응. 버그를 고쳐 달라고 해서 봤는데, 아무리 고쳐도 안 되더라고.

유미나 : 그런데 웬 작은 애가 화면에서 지나가는 거야. 그래서 말을 걸어 봤지.

엄마 : 말을 걸어? 누구한테?

유미나 : 귀신한테.

엄마 : ...네가 귀신을 봤다고?

유미나 : 응! 나도 처음엔 잘못 본 줄 알았는데, 대답도 하더라니까?

엄마 : 미나야, 잠깐만. 정말 네 눈으로 보고, 대화까지 했다는 거니?

유미나 : 그렇다니까. 생각보다 귀엽게 생겼더라. 말도 잘 듣고.

엄마 : 지금도 거기 있어? 일단 함부로 건드리지 말고...

유미나 : 아, 벌써 성불했어.

엄마 : ...뭐?

유미나 : 방에 퇴마 책 있잖아. 그거 찾아서 적힌 대로 해 봤더니 되던데?

엄마 : 네가 직접 성불까지 시켰다고?

유미나 : 응. ...엄마?

나레이션 : 전화 너머가 잠시 조용해졌다.

엄마 : ...세상에. 이런 일이 다 있네.

유미나 : 그거, 많이 대단한 일이야?

엄마 : 대단하지. 우린 있는지 알아내기도 힘든데, 넌 보고 말도 걸고... 보내 주기까지 했으니.

유미나 : 나처럼 할 수 있는 사람은 없어?

엄마 : 적어도 엄마가 아는 사람 중에는 없어. 너처럼 인터넷에서 귀신의 본체를 봤다는 사람도 처음이고.

유미나 : ...그럼 나, 이걸 일로 해도 되는 거 아니야?

엄마 : ...일?

유미나 : 인터넷 귀신 말이야. 못 해결한 일이 많다며. 내가 해결하면 되잖아!

엄마 : 미나야. 오늘 만난 애는 순했어도, 다른 귀신들까지 그렇지는 않을 거야.

유미나 : 알아. 나도 무서운 건 싫지. 그래도...

나레이션 : 책상 위의 퇴마 책이 눈에 들어왔다.

유미나 : 나도 할 수 있는 게 있잖아. 퇴마사 일 중에.

엄마 : ...

유미나 : 엄마, 나 퇴마사 해 볼래.

엄마 : ...정말 해 보고 싶니?

유미나 : 응. 이번엔 내가 직접 보고 할 수 있는 일이니까.

엄마 : ...그래, 우리 딸이 원한다면야.
엄마 : 하지만, 이 말만은 명심해줘.

엄마 : 절대 혼자 해결하려고 하지 말고, 엄마랑 아빠한테 최대한 도움요청할 것.

엄마 : 엄마랑 아빠도 도와줄 수 있는 것 최대한 도와줄 테니, 안전하게 해주렴.

유미나 : 헤헤. 알았어. 고마워, 엄마!

(통화가 끝난다.)

나레이션 : 휴대전화를 내려놓았다. 자꾸 입꼬리가 올라가서, 괜히 한 번 헛기침을 했다.

유미나 : 으흠\~ 나밖에 못 하는 일이라는 거잖아!

유미나 : 그럼 이걸 뭐라고 부를까\~? 그냥 퇴마사는 아니니까...

(화면 전환. 게임 로고가 나타난다.)

유미나 : "사이버 퇴마사"!!
