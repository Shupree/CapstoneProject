# 탐색 검색 게시물

현재 탐색 씬에 배치하는 게시물 원고. 같은 검색어 안에서는 아래 순서를 유지한다.
일반 검색 8개와 강령술 검색의 첫 8개에는 수집 단서가 없다. 강령술 검색 9번째는 의뢰인의 게시물이며 본문을 클릭하면 기존 `mary_comment` 증거를 수집한다. Bloody.org 이름은 강령술 검색 2·3·6번 본문에만 둔다.
Bloody.org는 게임 내부의 사이트 이름이며 실제 외부 사이트로 연결하지 않는다.
본문의 link·veil·revealed 태그는 기존 단서 및 퇴마 프로그램 표시용이다. 원고 수정만으로 씬의 Site Entries가 자동 갱신되지는 않는다.
