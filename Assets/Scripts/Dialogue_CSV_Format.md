# 대사 CSV 형식

기존 대사 CSV 가이드를 복사해 형식 설명과 예시만 남긴 문서다. MD 스크립트를 먼저 작성하고 사용자가 요청할 때 이 형식으로 변환한다. CSV는 각 파트 폴더에 대상 MD와 같은 기본 이름으로 저장한다.

## 컬럼 설명

| 컬럼 | 작성 방법 |
| --- | --- |
| SceneID | 대화 묶음 ID. Unity 씬 이름과 자동 연결되지 않는다. 대소문자를 구분한다. 같은 묶음의 빈칸은 이전 ID를 이어받는다. |
| Order | 묶음마다 1부터 시작하는 정수. 중복·누락 없이 연속으로 작성한다. |
| SpeakerID | 화자 ID 또는 표시 이름. 나레이션은 나레이션으로 표기하며 실제 표시 시스템의 매핑을 확인한다. |
| Dialogue | 대사·나레이션 본문. 쉼표·줄바꿈·큰따옴표가 있으면 셀을 큰따옴표로 감싼다. 내부 큰따옴표는 두 번 쓴다. |
| Image | 실제 연결된 이미지 ID. 모르면 비워 둔다. 자동으로 Sprite를 찾는 기능은 아니다. |
| EventID | 실제 연결된 이벤트 ID. 모르면 비워 둔다. 리더가 자동 실행하지 않는다. |

여섯 헤더는 모두 필요하다. UTF-8 BOM CSV로 저장한다. 컬럼 설명은 CSV 데이터 행에 넣지 않는다. 설명 행의 Dialogue가 채워져 있는데 Order가 비어 있으면 오류가 나므로 이 문서를 형식 안내로 사용한다. MD의 연출 지문을 임의로 발화나 미구현 이벤트로 바꾸지 않는다.

## 작성 예시 — 두 줄

아래는 형식 확인용이며 실제 스토리 대사가 아니다. Image와 EventID는 연결 정보가 없어 비워 두었다.

```csv
SceneID,Order,SpeakerID,Dialogue,Image,EventID
Example_Conversation,1,유미나,"좋아, 시작해 볼까?",,
Example_Conversation,2,나레이션,나는 메일을 열었다.,,
```
